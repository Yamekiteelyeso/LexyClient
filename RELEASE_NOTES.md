# LexyClient 1.5.0 Blue Edition

- Right Shift opens full module browser; Left Shift closes it (in-game and from title screen entry).
- Accessible All Modules view with visible page navigation, categories and search.
- Animated-style graphite/blue GUI with original generated LexyClient emblem in the GUI, title screen and mod list.
- Title-screen LexyClient entry with blue theme and shortcut help.
- AutoTotem is a real inventory offhand SWAP via vanilla screen handler (default OFF). Only when empty, low-HP mode, HP threshold, tick interval, notification. May violate multiplayer server rules.
- More HUD settings: configurable low-health alerts, armor durability alerts, text colors, spacing and opacity.
- Optimization presets and Spotify Connect / local music remain.
- Use Minecraft 1.20.1, Fabric Loader and Fabric API. Build using Gradle 8.11.1 with JDK 17.
- Spotify Connect still needs Spotify desktop/web-compatible player, Spotify does not expose its music streams to Minecraft mods.
