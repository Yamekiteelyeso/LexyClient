# 1.6.0 — Responsive UI & HUD editor

- Fixed-size layouts replaced by an adaptive scaled ClickGUI (including hitboxes, text inputs, tooltips, category navigation and scrolling).
- User-facing Menu Size preference (70–110%) and separate HUD Size (45–150%).
- Prominent MOVE HUD button in the top bar and sidebar.
- True in-game HUD editor with real FPS/Ping widgets, drag-and-drop, normalized resolution-independent saved positions, optional snapping/grid and +/- scale controls.
- Spotify authorization UI redesigned: LOGIN WITH SPOTIFY launches PKCE browser login; GET CLIENT ID launches Spotify developer app portal. Explicit redirect setup instructions.
- Kept Right Shift open, Left Shift close, Ctrl Right editor, AutoTotem opt-in, FPS optimization, Local Music.
