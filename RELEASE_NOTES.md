# LexyClient 2.8.0 — UI refresh

- New darker graphite and blue two-column ClickGUI, redrawn sidebar and primary buttons.
- Twelve sections with colored identifiers, active category states and smooth hover transitions.
- Improved module cards, online/active status and brief caching of dashboard metrics.
- Independent Cheat-section active indicators (AutoTotem, TriggerBot, Aim Assist and AutoClicker).
- Redesigned Keybinds & Macros screen; improved HUD editor palette and menu branding.
- Right Shift now reliably toggles the main menu; the shortcut also closes open keybinding and HUD editor overlays. Left Shift is not the closing shortcut.
- Escape remains a conventional back/close key; Ctrl+F focuses search on module tabs.
- Refined content clipping and scroll/navigation controls, with the original settings and modules retained.

Compile target: Minecraft 1.20.1, Fabric Loader, Fabric API, Java 17. Runtime tests on a real game/client are still required.
