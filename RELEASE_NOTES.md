# LexyClient 2.0.0

- Strict HUD whitelist: optimization and performance stats can never appear as in-game widgets, even when enabled in older config.
- Configurable 3–10 HUD widget limit (default 7) and cleaner relevant-only HUD.
- Four original OGG UI sounds: tap, toggle, open, close; appearance controls for mute and volume.
- Spotify mobile login: Android intent browser opening, clipboard link, manual state-verified PKCE callback paste, better diagnosis and separate connected/login panels.
- PC support and Fabric 1.20.1 retained.
- Compiles with Java 17. Device runtime compatibility still needs hands-on testing.
