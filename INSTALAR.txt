LEXYCLIENT 2.5.0 / MINECRAFT JAVA 1.20.1 FABRIC
1. Remove previous LexyClient .jar files from mods.
2. Install Fabric Loader and Fabric API for Minecraft 1.20.1.
3. Copy lexy-client-2.5.0.jar into mods. Use Java 17.
4. Open with Right Shift / pause menu; configure Keybinds in client or Minecraft Controls.
5. Local Music accepts your own MP3/WAV/AIFF files; Spotify Free catalog audio is not streamed inside Minecraft.
