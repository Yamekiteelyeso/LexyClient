LexyClient 4.2.0 — Minecraft Fabric 1.20.1 (Java 17)

1) Close Minecraft. Remove OLD lexy-client JARs from the active profile's mods folder.
2) Copy ONLY lexy-client-4.2.0.jar to mods (NOT this ZIP).
3) Ensure Fabric Loader and Fabric API match 1.20.1.
4) Open game: RSHIFT / F8 / /lexy; HUD editor: Right Ctrl.
5) If the mod does not appear in latest.log under Loading mods, the launcher is using a different mods folder.

The HUD migration keeps saved widget positions and toggles; its size is set to compact once for pre-4.2 configs.
