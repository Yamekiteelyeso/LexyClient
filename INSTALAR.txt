LEXYCLIENT 3.0.0 — MINECRAFT JAVA 1.20.1 + FABRIC

1. Cierra Minecraft y elimina LexyClient anteriores de mods.
2. Instala Fabric Loader + Fabric API para 1.20.1.
3. Copia lexy-client-3.0.0.jar a mods y arranca el PERFIL FABRIC.
4. Abre con Shift derecho, F8, boton LEXY del título/pausa o /lexy en mundo.
5. Si no aparece: /lexy status; adjunta .minecraft/logs/latest.log.
